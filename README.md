# Gemini-Chatbot
A simple, lightweight Python terminal chatbot powered by Google's latest **Gemini 3.5 Flash** model. This project demonstrates how to use the official Google GenAI SDK to create a stateful, multi-turn conversation directly in your terminal.

---

## ✨ Features

- 💬 **Conversational Memory** — Maintains full context across turns so you can ask natural follow-up questions
- ⚡ **Gemini 3.5 Flash** — Powered by Google's latest fast and capable model
- 🔐 **Secure API Key Handling** — Uses `python-dotenv` to load credentials from a `.env` file; no hardcoded secrets
- 🪶 **Lightweight** — Minimal dependencies, runs entirely in your terminal
- 🔄 **Easy to Extend** — Clean, readable code you can build on

---

## 🛠️ Prerequisites

- Python **3.8+**
- A free Gemini API key from [Google AI Studio](https://aistudio.google.com/)
